How it works

Clockoli uses GitHub Device activation, so you never need to create or paste a personal access token.

Use device codes safely

Only enter a code after starting this connection here. Clockoli requests the code directly from GitHub and displays it locally. On GitHub, verify that the page names Clockoli. Cancel if you did not initiate the flow or received the code from another person.

What “Act on your behalf” means

Clockoli can verify your GitHub identity, discover Clockoli App installations available to you, and read or write only repositories you later grant to the App. It cannot change account or organization settings or access ungranted repositories.

A “new” or “few users” message on GitHub is an age and adoption notice, not an extra permission.

Billable rates

Set hourly rates for people whose time appears in Clockoli reports. Add date ranges if a rate changes over time. Rates are private to this browser; hourly rates and calculated amounts are never written to your GitHub repository.

Leave End date empty if the rate is still current. Clockoli applies it through today and keeps it current until you add a later rate period.

Backup & restore

Export your local Clockoli settings to move them to another browser or keep a backup. Time entries and GitHub credentials aren’t included.

What is included?

The backup includes display settings, billable rates and repository coordinates. GitHub credentials and time entries are never included. The downloaded file stays under your control and can be restored offline; importing repository coordinates does not reconnect GitHub or change the active data repository.
