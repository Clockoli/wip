  • Clockoli requests only the repository access needed to read and write your data.

How it works

Clockoli uses GitHub Device activation, so you never need to create or paste a personal access token.

Use device codes safely

Only enter a code after starting this connection here. Clockoli requests the code directly from GitHub and displays it locally. On GitHub, verify that the page names Clockoli. Cancel if you did not initiate the flow or received the code from another person.

What “Act on your behalf” means

Clockoli can verify your GitHub identity, discover Clockoli App installations available to you, and read or write only repositories you later grant to the App. It cannot change account or organization settings or access ungranted repositories.

A “new” or “few users” message on GitHub is an age and adoption notice, not an extra permission.

    Use a personal access token

    This single-repository compatibility option is for existing PAT setups or environments where the GitHub App cannot be installed. Personal access token compatibility mode supports one time repository only. Clockoli never displays a stored token.

    Create a fine-grained personal access token restricted to one private repository with Contents: Read and write.

    Repository used by this token
    Authentication

    Stored only in extension-local IndexedDB. It is never exposed to GitHub pages, URLs, analytics, or time-data files.

    Recovery and access

    Removes local settings, credentials and unsynced local state from this browser. Before clearing, stop any running timer and use Sync until no pending changes remain. Repository data is not deleted.

    Revoke GitHub sign-in

    Remove Clockoli’s sign-in approval from your GitHub account. This does not uninstall the App or delete repository data.
