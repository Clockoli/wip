Device activation

Device activation securely signs this RepoClock extension in to GitHub without asking you to create or paste a personal access token.

Why GitHub warns about device codes

Only use the code after you start Device activation in this extension. GitHub warns against codes sent by someone else because they could connect an app you did not choose. RepoClock requests this one-time code directly from GitHub and shows it here. On GitHub, verify that the page names RepoClock by RepoClock. If you did not start this process, cancel it.

What “Act on your behalf” means here

This is GitHub’s standard wording for limited API calls made with your approval. RepoClock can verify your GitHub identity, find RepoClock installations you can access, and—only after you grant a repository—read and write that repository’s contents. It cannot access repositories you do not grant or change your account or organization settings.

During beta, GitHub may say RepoClock is new or has few users. That is an age and adoption notice, not an additional permission.

Create repoclock-data on GitHub

GitHub opens a prefilled form. Review it and select Create repository. Repository creation does not grant RepoClock access; that is Step 3.

Give RepoClock access to a data repository

Grant RepoClock access to the newly created repository or an existing private repository. Choose Only select repositories on GitHub.

Choose repository access on GitHub
